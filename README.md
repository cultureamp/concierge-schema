# concierge-schema

Public JSON Schema for repo-root [`concierge.yaml`](https://github.com/cultureamp/agent-workflows/blob/main/docs/workflow-helpers.md#declared-siblings-conciergeyaml).

Do not edit this repository. It is published from [`cultureamp/agent-workflows`](https://github.com/cultureamp/agent-workflows) (`packages/framework/schemas/concierge.schema.json`) on every change to `main`.

Point yaml-language-server at it:

```yaml
# yaml-language-server: $schema=https://raw.githubusercontent.com/cultureamp/concierge-schema/main/concierge.schema.json
```
